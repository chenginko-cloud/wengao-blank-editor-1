# 空白文稿编辑器

沿用 [全部文稿总库](https://github.com/chenginko-cloud/wengao-reader-2026) 的桌面、手机页面布局与七组筛选结构，初始没有任何文稿或筛选项。可在「编辑筛选页」配置分类，在阅读页新增、编辑、复制、删除文稿；支持搜索（含正文）、排序、桌面分页、手机分批加载和侧边滑动手势。

数据保存在当前浏览器的 localStorage，按项目路径隔离，不会自动发布到 GitHub、跨设备同步或被访问同一网址的其他人看到。请定期用「导入 / 导出」备份 JSON；导入会覆盖当前项目的本地数据。清除浏览器站点数据会移除未备份的内容。

纯静态文件，GitHub Pages 从 main 分支根目录发布。`index.html` 根据设备进入 `desktop.html` 或 `mobile.html`。
