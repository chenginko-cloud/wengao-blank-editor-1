# 空白文稿编辑器一 · 三级目录与跨设备同步

静态 GitHub Pages 文稿编辑器。原链接保持不变：`index.html` 自动进入桌面版或手机版，`desktop.html` 和 `mobile.html` 均使用三级目录及全屏阅读、编辑页。

- 左侧目录最多三级。可新增、重命名、删除目录；删除目录时，其中的文稿移至「未分类」，文稿本身不删除。
- 筛选页始终展开一级目录，二级目录直接可见；三级小节可点击章节旁的箭头展开。
- 目录页只显示文稿标题和正文两行预览；可按标题或正文搜索。
- 点击已有文稿先进入只读页；点「编辑」才可修改标题、所属目录及正文，点击保存或使用 Ctrl/Cmd+S。新建文稿直接进入编辑页。
- 手机端可在列表右滑打开目录、目录左滑返回列表；阅读页与编辑页从屏幕左边缘右滑逐级返回，未保存修改时会先确认。
- 本机浏览器数据始终保留，也能用「导入 / 导出」备份 JSON；旧版数据会转换为三级目录。

## 跨设备同步

点页面顶部的「☁ 未连接」，在每台设备输入**同一枚 Gist Token**（用户提供的部署凭证文件中的 Gist Token，非仓库 Token）。仅在用户连接后，网页才向 GitHub Gist 上传数据。网页代码只包含 Gist ID，不包含 Token。Token 默认只在当前页面内存中使用，重新打开页面需要再次输入。「在此设备记住凭证」会将 Token 保存在浏览器本地存储；同一 GitHub Pages 域名下的其他页面也可能读取它，只应在可信的私人设备上使用。断开会清除浏览器保存的 Token，不删除本机文稿或云端内容。

文稿在浏览器里用该 Token 经 PBKDF2 派生的 AES-GCM 密钥加密，再上传到 secret Gist。GitHub secret Gist 仍可由知道地址的人访问，所以必须保留加密。**请备份 Token 和 JSON 数据**：Token 丢失或更换后旧云端密文无法解密。不要把 Token 放在 URL 或分享给他人。

连接后会在保存文稿或修改目录时上传，并在页面打开期间定期检查云端；断网时保留本机修改，恢复网络后重试。发现本机和云端同时修改时，会暂停覆盖并让用户选版本；可先下载本机备份。GitHub Gist 不提供此接口的原子条件写入，若两台设备同时保存同一数据，可能发生版本冲突；请在其中一台保存完成后再切换设备。单次加密数据上限约 900 KB，超出时本机数据仍可导出。
