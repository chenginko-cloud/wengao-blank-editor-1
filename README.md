# 空白文稿编辑器 · 三级目录版

静态 GitHub Pages 文稿编辑器。原链接保持不变：`index.html` 自动进入桌面版或手机版，`desktop.html` 和 `mobile.html` 均使用响应式目录及全屏编辑页。

- 左侧目录最多三级。可新增、重命名、删除目录；删除目录时，其中的文稿移至「未分类」，文稿本身不删除。
- 点击目录查看其下所有层级的文稿。目录页只显示文稿标题和正文两行预览；可按标题或正文搜索。
- 点击文稿打开全屏编辑页：顶栏可编辑标题、归属目录并保存；下方直接编辑正文。支持 Ctrl/Cmd+S。关闭未保存的内容时会提醒。
- 本地浏览器数据通过项目路径隔离。JSON 导出用于备份，导入会覆盖当前项目的数据。GitHub Pages 不提供云同步，换浏览器或设备需手动导入。
- 会读取旧版本的本地数据，保留文稿标题与正文，按旧「内容库 → 主题大类 → 细分主题」分类尽可能转换为三级目录。文章的其他旧字段仍保留在备份 JSON 中。
